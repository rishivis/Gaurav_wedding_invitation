# Royal Indian Wedding Invitation Website (Shubh Vivah)

A rich, culturally authentic Indian Wedding Invitation website featuring:
1. **3D Royal Haveli Door Intro**: Animated carved wooden & brass palace doors with a marigold *Toran* (`तोरण`) that swing open on click.
2. **Synthesized Indian Classical Wedding Music**: Built-in Web Audio API (via Tone.js) playing a continuous *Tanpura* drone, *Shehnai* Raag Yaman melody, *Sitar* accompaniment, and festive *Tabla/Dhol* beats—no external MP3 files required.
3. **Baraat & Family Procession Scene**: Animated cultural SVG illustration of the Groom's family (`वर पक्ष`), the Bride & Groom under the *Phoolon Ki Chaadar*, and the Bride's family (`वधू पक्ष`) welcoming guests' families with folded hands (`Namaste`).
4. **Colorful Indian Wedding Ceremonies**: Dedicated cards for *Haldi*, *Mehendi & Sangeet*, *Swagat & Baraat*, and *Varmala & Saptapadi*.
5. **Wedding Location & Interactive Map**: Illustrated landmark trail + live Google Maps embed + direct navigation link.
6. **Live Customization Drawer**: Click **✨ Customize** in the bottom-right corner to edit the Groom & Bride names, Parents' names, Date, and Google Map location live.

## How to Run
Simply unzip the folder and double-click `index.html` to open it in any modern web browser (Chrome, Edge, Safari, Firefox).
